Cette page publie vos logos, affiches et flyers directement dans la galerie Design du portfolio. Elle ne fonctionne qu'avec votre clé GitHub personnelle : un visiteur qui tombe dessus ne peut rien modifier.

1 · Connexion

Comment obtenir cette clé (une seule fois, 2 minutes)
  1. Ouvrez github.com/settings/personal-access-tokens/new.
  2. Nom : Portfolio admin. Expiration : 1 an.
  3. Repository access : « Only select repositories », puis choisissez Aramayac.github.io.
  4. Permissions → Repository permissions → Contents : « Read and write ».
  5. Cliquez sur Generate token, copiez la clé et collez-la ci-dessus.

Cette clé ne donne accès qu'au dépôt du portfolio. Ne la partagez avec personne. Si vous la perdez, supprimez-la sur GitHub et créez-en une nouvelle.
